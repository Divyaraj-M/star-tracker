Star Tracker 1.4.0

- Several trackers: create as many as you want, each with its own folder, base and task tag. Task tags in settings now take a comma-separated list.
- Tracker icon in the left ribbon and an "Open a tracker" command. One tracker opens straight away; with several, a list pops up (Enter opens, Mod+Enter opens in a new tab, Shift+Enter opens to the right).
- Boards made by "Create a tracker" add the tracker's tag to new cards.
