Star Tracker 1.5.0

- Settings per tracker: pick a tracker at the top of the settings page and give it its own statuses, stages, priorities, types, field names, card fields and sprint options. Trackers without their own settings keep using the main settings.
- "Create a tracker" can start a tracker with its own settings.
- Status history, "Add missing fields" and sprints use the settings of the tracker a task belongs to.
