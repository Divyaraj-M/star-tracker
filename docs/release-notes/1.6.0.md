Star Tracker 1.6.0

- Activity timeline: a new Star activity view and an "Open activity timeline" command. Shows notes created and edited (with the changed text), captures from folders you pick, ticked or cancelled checkboxes, and task status changes, by day, week, month or year. Sidebar has a 10-week heatmap, counts by type and a folder filter.
- Activity for each task: a history icon in every note's header (next to the edit button, can be turned off in settings), "Show activity" on a card's menu, an Activity button in the card popup, and "Show activity for this note" for any note. Older status moves are read from status_log.
- New trackers get an Activity view limited to the tracker's tasks.
- The log is stored as JSON lines per month and per device, so synced vaults do not clash.
